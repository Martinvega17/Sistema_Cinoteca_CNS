Registros de hoy (pruebas)

Elimina todos los accesos capturados hoy y reinicia el folio a 001. Es permanente y no se puede deshacer — úsalo solo para limpiar registros de prueba.

Borrar TODO el historial

Elimina TODOS los accesos de la base de datos, de cualquier fecha (no solo hoy), y reinicia el folio a 001. Es permanente y no se puede deshacer. Pide confirmar dos veces (ventana de confirmación + escribir "BORRAR"); el sistema guarda automáticamente una copia completa de los registros antes de borrarlos.

"Borrar TODO el historial" solo puede solicitarla una cuenta con rol "Responsable institucional". Si necesitas ejecutarla, pide a esa cuenta que inicie sesión.
